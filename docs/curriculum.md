# Two-Month Curriculum (2026-08-13 → 2026-10-13)

The "training" is encoded, not vibes: every rule is backtested before going live,
every paper decision is journaled with reasoning, and the user grades the journal.
At day 60 the user decides: continue / modify / stop.

## Weeks 1–2 — Build
- Phase 0–1: scaffold, datafeed, portfolio tracker, first HTML report
- Phase 2: risk dashboard
- Phase 3: backtester + candidate strategies (SET trend/momentum, US momentum)
- Phase 4: paperbot goes live on paper (target: week 2)
- Phase 5: scheduled digests (08:30 + 17:45 ICT)
- **Thu Aug 27**: user registers for Settrade Open API (reminder scheduled)

## Weeks 3–8 — Operate & learn
- Daily: EOD runs, digest, one-line "grade yesterday's calls" prompt (10 seconds)
- Weekly (~15 min, the main event): walk the journal, adjust rules, record lessons
- Monthly: performance report vs SET TRI, S&P 500, and cash

## Day 60 deliverables
- Audited paper track record (every trade + reasoning + grade)
- Written playbook: which rules earned their place, which died, and why
- User's continue/modify/stop decision
